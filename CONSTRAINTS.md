# Constraints

Durable MUST / MUST NOT rules. Each has a short reason. Add a rule only when a feature reveals one.

- **MUST** serve only `public/`. Never place PHP sources, config, tests or SQL under `public/`. *Reason: everything else may hold secrets or internals.*
- **MUST** use relative URLs in the frontend (`assets/...`, `api/...`), never root-absolute ones (`/api/...`). *Reason: the app runs at `/` under `php -S` and at `/devexpertai/` under the XAMPP Alias.*
- **MUST** keep secrets only in the git-ignored `config/config.php`. `config/config.example.php` holds placeholders (`CHANGE_ME`) only. *Reason: secrets must never reach git, logs or code.*
- **MUST** write tests as plain PHP `tests/**/*_test.php` files returning `array<string, callable>`, run by `php tests/run.php`, using the helpers in `tests/lib/assert.php`. **MUST NOT** use PHPUnit or PHP's `assert()`. *Reason: no dependencies beyond W3.CSS and the two local fonts; `assert()` depends on `zend.assertions`.*
- **MUST** keep W3.CSS vendored and byte-for-byte unmodified at `public/assets/vendor/w3css/w3.css`, with `SOURCE.txt` (URL, version, date, SHA-256) updated on any upgrade. App styles go in a separate stylesheet. `public/assets/vendor/**` is `-text` in `.gitattributes` so line endings are never converted. *Reason: pinned, offline, verifiable third-party code.*
- **MUST** load fonts only from the vendored files, unmodified with SHA-256 in each `SOURCE.txt` and checked by tests: icons from Material Symbols Outlined (`public/assets/vendor/material-symbols/`, via `public/assets/css/icons.css`, `tests/bootstrap/icons_test.php`) and text from Source Sans 3 (`public/assets/vendor/source-sans-3/`, via `public/assets/css/fonts.css`, `tests/bootstrap/fonts_test.php`). **MUST NOT** link Google Fonts, `fonts.gstatic.com` or any other CDN. *Reason: the app must work offline on XAMPP, and the user approved exactly these two fonts as extra dependencies (2026-11-27).*
- **MUST** spawn PHP subprocesses with the array form of `proc_open` (`[PHP_BINARY, ...]`), and always terminate them. *Reason: on Windows the string form runs through `cmd.exe`; terminating it can orphan `php.exe`.*
- **MUST** keep `./init.sh` LF, executable (100755) and non-blocking (no long-running servers). *Reason: it is the standard gate for every session.*
- **MUST NOT** name a database in `db/*.sql` (no `CREATE DATABASE`, `DROP DATABASE` or `USE`); scripts run against the database given on the mysql command line. *Reason: each worktree uses its own `hm_*` database, and a hard-coded name could hit another one.*
- **MUST** run destructive DB tests only against databases named `hm_*` (`^hm_[a-z0-9_]+$`); `tests/lib/db.php` skips otherwise. **MUST NOT** point tests at `hotel_maintenance` or another worktree's database. *Reason: the tests drop and recreate every table.*
- **MUST** keep `db/*.sql` splittable: every statement ends with `;` at the end of a line, comments are full `--` lines, no `;` inside comments or string literals, no `DELIMITER`. *Reason: `tests/lib/db.php` applies the scripts statement by statement with a simple line splitter.*
- **MUST** store status and priority as the exact Spanish strings of `CONTEXT.md`, enforced by `CHECK (CAST(col AS BINARY) IN (...))` (byte comparison), not ENUM and not `COLLATE utf8mb4_bin`. *Reason: the server `sql_mode` is not strict (a bad ENUM becomes `''`), the table collation `utf8mb4_unicode_ci` would accept `pendiente` or `En resolucion`, and `utf8mb4_bin` is PAD SPACE on MariaDB 10.4 so it would accept `Pendiente `.*
- **MUST NOT** download W3.CSS (or other files from w3schools.com) with curl's default User-Agent; pass a browser User-Agent with `-A`. *Reason: the site returns 403 to curl's default User-Agent.*
